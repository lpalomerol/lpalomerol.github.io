Manifiesto

Cómo trabajo, qué defiendo y qué no haré. Un marco de principios para que sepas exactamente qué esperar cuando trabajamos juntos.

Anti-pilares

Si buscas esto, probablemente no soy la persona adecuada.

✕

Poner un transformer donde basta una regresión logística.

✕

Optimizar el 0.1 % de AUC a costa de explicabilidad.

✕

Entregar un notebook con celdas fuera de orden.

✕

Decir "funciona en producción" sin haberlo visto.

✕

Usar IA para generar código que no entiendo.

Pilares

Los principios que guían cada pipeline, cada modelo, cada entrega.

1. Reproducibilidad y robustez

En producción no hay "en mi máquina funciona"

  • Versiones de todo: código, datos, dependencias, entorno.
  • Pipelines deterministas. Semilla fija. Orden explícito.
  • Cada pipeline en un contenedor.
  • Los experimentos dejan traza ejecutable.

2. Altos estándares de programación

El código es para quien lo leerá dentro de 6 meses

  • Type hints. Tests. Nombres que explican intención.
  • Una función, una responsabilidad.
  • El testing es red de seguridad, no métrica.
  • Código aburrido y correcto > código brillante y frágil.

3. Simplicidad radical

El mejor método es el que puedes explicar en métodos

  • Regresión logística bien construida > red neuronal opaca.
  • Cada transformación tiene un porqué.
  • Si necesita tutorial de 20 min, busca alternativa.
  • La complejidad se justifica, no se asume.

4. Narrativa coherente

Cada análisis cuenta una historia

  • Pipeline legible como artículo: intro, métodos, resultados.
  • Código como narrativa. Comentarios explican el porqué.
  • Outputs con contexto. Un número sin significado no es resultado.
  • El investigador cuenta la historia; le doy herramientas.

5. IA como herramienta de soporte

Acelera, no decide

  • La IA me ayuda a escribir tests, refactorizar, explorar.
  • La IA no toma decisiones metodológicas ni interpreta resultados.
  • Todo output de IA se revisa. Sin excepción.
  • Uso IA para eliminar trabajo tedioso, no pensamiento crítico.

¿Resuena contigo?

Si esta forma de trabajar encaja con lo que buscas, hablemos.
